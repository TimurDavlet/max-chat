# MAX Чат — тестовое задание (React)

Простой веб-интерфейс для отправки и получения текстовых сообщений в мессенджере MAX через [GREEN-API](https://green-api.com/max). Внешний вид - по мотивам web.max.ru: список чатов слева, переписка справа, градиентные исходящие сообщения.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
```

## Как пользоваться

1. Откройте приложение и введите `idInstance` и `apiTokenInstance` из [личного кабинета GREEN-API](https://console.green-api.com). Инстанс должен быть авторизован (QR-код в кабинете).
2. Введите номер телефона получателя (РФ `+7…` или РБ `+375…`) и нажмите «Создать чат».
3. Напишите сообщение и отправьте (Enter — отправить, Shift+Enter — новая строка).
4. Ответ получателя из MAX появится в чате автоматически.

### Настройка инстанса

Сообщения принимаются через HTTP API (опрос очереди), поэтому в настройках инстанса:

- включены уведомления о входящих сообщениях (`incomingWebhook: yes`);
- поле `webhookUrl` **пустое** — иначе `ReceiveNotification` вернёт ошибку (приложение покажет подсказку).

## Использованные методы GREEN-API

| Назначение | Метод |
| --- | --- |
| Проверка учётных данных при входе | `GET getStateInstance` |
| Получение `chatId` по номеру телефона | `POST checkAccount` |
| Отправка текста | `POST sendMessage` — [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/) |
| Получение сообщений | `GET receiveNotification` + `DELETE deleteNotification` — [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/) |

Адрес API строится из первых четырёх цифр `idInstance` (`3100123456` → `https://3100.api.green-api.com`). Если у вашего инстанса другой адрес, укажите его на экране входа в разделе «Дополнительно».

## Структура

```
src/
  api.ts                  клиент GREEN-API
  storage.ts              токен и история чатов в браузере
  utils.ts                телефон, даты, аватары
  hooks/useNotifications  цикл ReceiveNotification → обработка → DeleteNotification
  hooks/useChatStore      состояние чатов и сообщений (useReducer)
  components/             LoginForm, Sidebar, NewChatForm, ChatWindow, ChatScreen
```

## Решения и ограничения

- Только текстовые сообщения и личные чаты. Группы и вложения игнорируются.
- Каждое уведомление удаляется из очереди после обработки; повторная доставка не создаёт дублей (дедупликация по `idMessage`).
- Сообщения, отправленные с телефона в тот же чат, тоже показываются.
- Неотправленное сообщение помечается ошибкой и его можно отправить повторно.
- Токен хранится в `localStorage` при включённой галочке «Запомнить меня», иначе только в `sessionStorage`. Токен уходит только на серверы GREEN-API.
- `StrictMode` отключён намеренно: в dev он запускал бы два параллельных опроса очереди.
- `CheckAccount` у MAX ограничен по частоте, поэтому для уже известного номера повторный запрос не делается.
